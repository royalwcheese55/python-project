Problem: Mini Distributed Task Scheduler
🎯 Overview

Design and implement a mini task scheduler that can execute tasks with:

Dependencies (DAG)

Concurrent execution

Retry mechanism

Task state management

This system is a simplified version of tools like Airflow / Celery / Cron systems.

📌 Requirements
1. Task Definition

Each task should include:

{
    "task_id": str,
    "func": callable,
    "args": tuple,
    "kwargs": dict,
    "dependencies": List[str],  # list of task_ids
    "retries": int,
    "retry_delay": int  # seconds
}
2. Scheduler API
Add a task
scheduler.add_task(task)
Execute all tasks
scheduler.run()
3. Functional Requirements
✅ Dependency Handling (DAG)

A task should only run after all its dependencies are completed successfully

If a dependency fails, downstream tasks should not run

✅ Concurrency

Tasks should run in parallel using a thread pool

Ensure thread-safe state updates

✅ Task States

Each task must track its state:

PENDING

RUNNING

SUCCESS

FAILED

RETRYING

SKIPPED

✅ Retry Mechanism

If a task fails:

Retry up to retries times

Wait retry_delay seconds between retries

✅ Error Isolation

A failed task should not crash the scheduler

Failure should only affect dependent tasks

4. Example
def task_a():
    print("A done")

def task_b():
    print("B done")

def task_c():
    raise Exception("fail")

scheduler.add_task({
    "task_id": "A",
    "func": task_a,
    "dependencies": [],
    "retries": 0
})

scheduler.add_task({
    "task_id": "B",
    "func": task_b,
    "dependencies": ["A"],
    "retries": 0
})

scheduler.add_task({
    "task_id": "C",
    "func": task_c,
    "dependencies": ["A"],
    "retries": 2,
    "retry_delay": 1
})

scheduler.run()
🔥 Expected Behavior

Task A runs first

Tasks B and C run after A completes

Task C retries on failure

Task D (if depends on C) should be skipped if C fails

💣 Constraints & Expectations

Write clean, modular, production-style code

Use classes and proper abstraction

Avoid global state

Ensure thread safety

Handle edge cases
